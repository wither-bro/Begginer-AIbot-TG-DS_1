## 🛠 ПОДРОБНОЕ ОБЪЯСНЕНИЕ СИСТЕМЫ
Проект SERIES(CG) — это высокотехнологичная среда обучения, разделенная на **5 автономных шлюзов (Classrooms)**.

* **Логика распределения:** Чтобы не было хаоса, все новички начинают с `Classroom_1`. Переход в следующие сектора (2-5) возможен только после того, как твой ID появится в `Students.md`.
* **Изоляция кода:** Каждый класс — это отдельная крепость. Если новичок залезет в 5-й класс и изменит там скрипты на Java или C++, он может «уронить» всё ядро проекта. Поэтому доступ туда строго ограничен.
* **Многозадачность:** Мы используем связку Python + Java + JS + C#. Каждый язык лежит в своей папке внутри класса. Порядок в папках = стабильность `CojAI`.

## 📚 ДОПОЛНИТЕЛЬНЫЕ СТРАНИЦЫ
В этом разделе собраны все важные документы проекта. Список ниже формируется путем сканирования репозитория на наличие `.md` файлов (исключая системные руководства).

```cpp
// Динамический поиск документации SERIES(CG)
#include <filesystem>
#include <vector>

void ScanDocuments() {
    std::string root = "./";
    for (const auto& file : std::filesystem::recursive_directory_iterator(root)) {
        if (file.path().extension() == ".md") {
            std::string name = file.path().filename().string();
            // Исключаем туториал и главный ридми из списка дополнений
            if (name != "tutorial.md" && name != "README.md") {
                std::cout << "* [" << name << "](" << file.path().string() << ")" << std::endl;
            }
        }
    }
}
