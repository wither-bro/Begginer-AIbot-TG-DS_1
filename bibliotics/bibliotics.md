# 📚 SERIES(CG) Studios: Official Bibliotics (2026)
Список актуальных библиотек для ядра "Begginer-AIbot-TG/DS".

---

## 🐍 Python (Bot Core)
Для главного движка в Telegram.
* **aiogram == 3.10.0+** (Используем только 3-ю ветку, она самая быстрая)
* **google-generativeai** (Для связи с Gemini 1.5 Pro/Flash)
* **python-dotenv** (Для защиты твоих API ключей)

## 🟨 JavaScript / Node.js (Web & Discord)
Для интеграции с Discord и веб-сервисов.
* **telegraf == 4.16.3+** (Король ботов на JS)
* **discord.js == 14.15.0+** (Если решишь расширять DS-версию)
* **axios** (Для мощных HTTP-запросов)

## ☕ Java (Core System)
Для твоего `CojAI.java` и тяжелых вычислений.
* **TelegramBots == 6.9.0** (Стандарт для Java-разработки)
* **Gson** (Для работы с JSON-профилями студентов)
* **Maven / Gradle** (Для управления сборкой)

---
> **Примечание для учеников:** Всегда используйте команду `pip install -r requirements.txt` или `npm install` для автоматической установки этих версий.
